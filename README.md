# ProofTube Protocol

> **Sovereign, peer-to-peer media protocol.**

ProofTube is an open, decentralized protocol for video sharing, content distribution, and cryptographic proof of ownership.

## 🚀 Vision & Key Features

* **Peer-to-Peer Distribution:** Decentralized hosting to eliminate single points of failure.
* **Censorship Resistance:** Built on open, sovereign identity frameworks (Nostr).
* **Proof of Ownership:** Cryptographic validation for content creators.
* **Open Source:** Licensed under MIT for community-driven development.
